## 1. 优先修复项（计算正确性与策略引导）

### 1.1 [x] `sage_eval` 不做 preparse、逐行编译，`print` 破坏子进程协议
- **修复文件**：`ai4math/tools/sage_tools.py`（`_run_sage_code`、`sage_eval`、`construct_proof`）、`ai4math/tools/sage_subprocess.py`（`main`）。
- **修复方案**：
  1. 实现统一执行器 `_run_sage_code`：整段代码先经 `sa.preparse()`，再用 `ast.parse(..., mode="exec")` 整块解析；若末条语句为表达式则单独 `eval` 作为返回值，若为单目标简单赋值则返回该变量值。
  2. 执行期间用 `contextlib.redirect_stdout` 捕获打印内容并写入返回 JSON 的 `stdout` 字段（`_format_tool_result_md` 同步渲染该字段）；同时在 `sage_subprocess.py` 的 `main()` 中将子进程标准输出重定向到 `stderr`，彻底杜绝任何工具的 `print` 破坏父子进程 JSON 通信协议。
  3. `construct_proof` 的 `setup_code`、`example_params` 与每步 `code` 全部复用 `_run_sage_code`。

### 1.2 [x] “高置信度定理指导”误注入到无关题目
- **修复文件**：`ai4math/llm/client.py`、`ai4math/tools/theorem_advisor.py`、`ai4math/tools/theorems/{algebraic_geometry,elliptic_curves,modular_forms}.json`。
- **修复方案**：
  1. `_build_preplan_context` 注入阈值改为 `(confidence == "high" and score >= 2.0) or score >= 4.0`，单靠 1 分泛化词命中不再触发强指导。
  2. 清理高置信度条目的泛化单字/泛化词（移除 `congruent_number_tunnell` 的裸 `rank`、`mock_theta_radial_limits` 与 `radial_limit_computation_recipe` 的裸 `limit`/`lim`/`finite sum`、`weil_zeta_curve` 的裸 `curve`/`曲线`/`zeta`；收紧 `eta_quotient_evaluation` 的正则 `(?<![a-zA-Z])eta(?![a-zA-Z])` 防止误匹配 `theta`/`beta`）。
  3. `_match_theorems` 对短英文词（长度 ≤ 4）启用词边界匹配，对 1–2 字泛化中文词降权为 `0.5` 分并要求总分 `>= 1.0` 才召回。

### 1.3 [x] 静默给出错误结果的工具
- **修复文件**：`ai4math/tools/algebra.py`、`ai4math/tools/probability.py`、`ai4math/tools/sage_tools.py`。
- **修复方案**：
  - `permutation_operation`：改用二维循环列表 `Permutation([cyc])` 正确解析循环记法，支持多循环自动对齐 `size`，新增实现 `operation="power"`。
  - `search_counterexample` / `verify_conjecture`：补充 `sa.preparse`；统计求值异常次数，全部出错时明确返回错误，部分出错时如实标注异常数。
  - `check_algebraic_structure`：校验 `n×n` 维度与无重复元素，建立 `elem_to_idx` 映射支持任意元素符号（如 `[1, -1]`）。
  - `polynomial_operation`：`lcm` 与 `roots` 完整支持 `modulus != 0`（在 `GF(p)[x]` 上因式分解提取重根，`x**2 - 1` mod 2 正确返回 `{1: 2}`）。
  - `compute_variance` / `_make_distribution`：将 `sp.Rational(v)` 改为 `sp.Rational(str(v))`，消除二进制浮点尾数膨胀。

### 1.4 [x] 按文档示例调用就失败的工具
- **修复文件**：`ai4math/tools/plotting.py`、`ai4math/tools/sage_tools.py`、`ai4math/tools/probability.py`、`ai4math/tools/analysis.py`、`ai4math/tools/_shared.py`。
- **修复方案**：
  - `plot_inequality_region`：运算符映射修正为 `less` / `less_equal` / `greater` / `greater_equal`。
  - `explore_structure`：用 `split_top_level(params, ",")` 保持列表参数完整，参数值与二次型均经 `sa.preparse`，`json.dumps` 统一带 `default=str` 并将 Sage `Integer` 转为 `int`。
  - `plot_function` / `plot_parametric` / `sage_plotting`：区间端点改用 `parse_float_expr`（支持 `-2*pi`、`2*pi`），多函数表达式改用 `split_top_level`（支持 `min(x, 0)`）。
  - `compute_probability`：基于 `ast.parse` 重写条件解析器，完整支持双侧链式不等式 `0.5 < x < 0.8`、绝对值 `abs(x) > 2` / `|x| > 1.96` 及 `and`/`or` 复合条件。
  - `compute_sum`：默认下界调整为 `lower="1"`，使 `1/n**2` 默认返回 `pi**2 / 6`。

### 1.5 [x] 批处理的 `--timeout` 不生效与错误统计失真
- **修复文件**：`ai4math/cli.py`。
- **修复方案**：移除死代码的 `as_completed` 超时写法，改为独立 `spawn` 子进程槽位池轮询每题单调时钟截止时间，超时立即 `SIGTERM -> SIGKILL` 清理整个进程组；区分 `ok` / `error` / `timeout` 三态写入 `summary.md` 与 `batch.log`。

## 4. 新增安全与协议漏洞修复清单（本次深度审计补充）

- [x] **4.1 进程内 SymPy 表达式注入防护**：`ai4math/tools/_shared.py` 的 `safe_parse_expr` 使用无 `__builtins__` 的白名单全局字典并在 `eval` 前做 AST 节点与私有属性（`_` / `__`）拦截，阻断 `__import__` 与对象继承链沙箱逃逸。
- [x] **4.2 子进程敏感凭证隔离**：`sage_subprocess.py` 的 `_child_env()` 自动剥离 `OPENAI_API_KEY`、`OPENAI_BASE_URL` 及所有 `*_API_KEY` / `*_SECRET` / `*_TOKEN` / `*_PASSWORD` 变量。
- [x] **4.3 多用户 `DOT_SAGE` 临时目录加固**：回退目录改为 `/tmp/ai4math_dot_sage_<uid>`，强制 `0700` 权限并通过 `os.lstat` 校验目录所有权与非符号链接，防止共享服务器权限冲突与 `init.sage` 投毒。
- [x] **4.4 外部定理库安全与去重方向修正**：外部 URL 强制校验 `https://`（本地回环除外）与 2 MiB 体积上限；修正 `theorem_advisor.py` 中 `merge` 模式的去重顺序为 `[*external, *builtin]`，与 README “外部优先”约定一致。
- [x] **4.5 商环多项式模幂防 DoS 与 `.env` 权限收紧**：`quotient_ring_operation` 改用二进制快速模幂 `_poly_pow_mod`；项目 `.env` 权限由 `0664` 收紧为 `0600`；`galois_group_chebotarev` 并行核数改为受控的 `AI4MATH_SAGE_WORKERS`。
- [x] **4.6 截断续写协议与定积分单边边界修复**：`client.py` 在 `finish_reason == "length"` 且含截断 `tool_calls` 时自动补齐错误 `role="tool"` 响应，避免触发 `400 Bad Request`，纯文本续写无缝拼接不插入多余空行；`integrate` 与 `sage_integrate` 对单侧缺失上下限明确报错。
